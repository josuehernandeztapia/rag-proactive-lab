# Prompt Library

- `pia/` – Templates y prompts del agente PIA. Incluye `manifest.json` con metadatos (versión, descripción, fecha). Usa `scripts/validate_pia_prompts.py` antes de desplegar para asegurar que todos los placeholders están cubiertos.
- (Reservado) Para nuevos agentes agrega subcarpetas (`guardian/`, `postventa/`, etc.) siguiendo el mismo patrón: manifest + script de validación.
